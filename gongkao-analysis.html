3用户场景分析 · When / Where / How

考公是一条数月到一年的长链路。真实 Query 分散落在链路各环节，说明用户"全周期都在用 AI"，这正是合作方按环节上架能力的机会点。

考公备考全链路 · 用户在每个环节问了什么

① 报考决策→ ② 备考规划→ ③ 知识学习→ ④ 刷题练习→ ⑤ 面试冲刺→ ⑥ 陪伴复盘
环节场景描述典型触发
① 报考决策选岗前的政策/机会/学历匹配咨询，多为一次性问答"考公一年几次机会""报考用哪个专业目录"
② 备考规划确定目标后，按考期倒排计划、分配科目，常带地域/身份上下文"备考北京遴选，住通州，帮我做计划"
③ 知识学习把视频/文档/教材提炼成知识块、思维导图，碎片时间高效学"从面试和申论梳理小模块""资料太多时间少"
④ 刷题练习每日出题、去重、组卷、可打印、错题重练，高频复用"每天出 10 道题不重复""生成可打印练习题"
⑤ 面试冲刺抓当天时政/面试热点，生成答题素材与观点框架"搜今天最新公考面试热点，近 2 天"
⑥ 陪伴复盘角色化专属助手，记住进度、督促、答疑、情绪支持"你是我的遴选专属学习助手"

场景特征提炼（对合作方最有价值的 3 点）

  • 强上下文 / 记忆诉求：用户主动交代地域、身份、考期、住址，期望 AI「记住我并持续服务」——非常适合角色化 Agent / 专属助手形态，而非一问一答。
  • 高频复用 / 结果可带走：出题、组卷、计划、知识块都要求「可持续、去重、可打印/可导出」——决定了能力必须支持状态保持与文件产出。
  • 时效敏感：面试热点强调"当天/近 2 天"，需要实时联网检索能力支撑，静态题库无法满足。

4用户需求分析 · What（按优先级）

把意图×场景收敛为可被"能力/功能"承接的具体需求，按「证据强度 × 复用频次 × 差异化价值」排优先级。

P0 · 智能题库与个性化组卷最高优先
按岗位类别（省考/事业编/社区工作者/遴选）出题、每日去重、按薄弱知识点组卷、错题本、A4 可打印导出。证据最直接、复用频次最高。
P0 · 考期倒排式备考规划最高优先
输入目标考试与日期，自动生成到考期的分科目学习计划，支持按身份/地域/基础个性化，并能每日跟踪督促。
P1 · 申论/面试热点与素材库高优先
实时抓取时政热点、面试真题与答题素材，按主题沉淀，支持"当天/近期"时效检索——需联网能力。
P1 · 资料提炼与知识块生成高优先
把视频/PDF/教材一键转成结构化知识块、思维导图、速记卡，服务碎片化高效学习。
P2 · 报考咨询与岗位匹配中优先
政策答疑（报考次数/学历目录/岗位限制）+ 按用户条件推荐可报岗位，服务决策期入口流量。
P2 · 角色化专属陪伴助手中优先
带记忆的"专属考公搭子"，记住进度、督学、答疑、情绪支持，提升长周期留存与粘性。

5给考公行业合作方的建议 · 能力上架 + 功能优化

以下建议可直接映射为 WorkBuddy 开放生态中的 Skill / 专家 / Connector 三类接入形态，并附功能优化要点。

🎯 建议上架能力 1：公考智能题库 Skill P0 · 建议首发
  • 形态：Skill（技能）+ 题库数据 Connector（对接合作方自有题库/真题库）
  • 必备功能：分考试类型出题、每日去重、按知识点/难度组卷、错题本沉淀、A4 打印导出
  • 优化要点：支持"连续多轮不重复"的会话记忆；答错自动加练同考点（呼应真实 Query）
🗓 建议上架能力 2：考期倒排备考规划专家 P0 · 建议首发
  • 形态：专家（Agent）—— 角色化"专属备考规划师"
  • 必备功能：按考试+日期+身份+地域生成计划、每日任务推送、进度看板、动态调整
  • 优化要点：首轮主动采集"考什么/何时考/现有基础/每日可用时长"，落地为可跟踪计划
📰 建议上架能力 3：申论面试热点素材库 P1
  • 形态：Skill + 实时资讯 Connector（权威媒体/政务源）
  • 必备功能：按主题聚合时政热点、生成面试答题框架与素材、支持"近 N 天"时效检索
  • 优化要点：务必接入实时联网，静态语料无法满足"当天热点"诉求
📚 建议上架能力 4：资料提炼与知识块生成 P1
  • 形态：Skill（文档/视频 → 结构化学习产物）
  • 必备功能：PDF/视频/教材转知识块、思维导图、速记卡、按考纲对齐
  • 优化要点：产物要"可带走"（导出/打印），呼应碎片化高效学习场景
🧭 建议上架能力 5：报考咨询与岗位匹配 P2 · 引流入口
  • 形态：专家（政策答疑）+ 岗位库 Connector
  • 必备功能：报考政策问答 + 按学历/专业/地域推荐可报岗位
  • 价值：卡位"决策期"入口流量，自然导流至备考能力，形成闭环
接入路径建议：优先以 P0 两项（智能题库 + 备考规划） 作为首发能力验证真实转化，再以 P1/P2 补齐全链路；同时建议在接入后开通专属场景埋点，用真实数据校准本报告中基于小样本推导的需求量级，滚动迭代能力矩阵。
